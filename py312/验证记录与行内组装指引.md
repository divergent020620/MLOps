## 4. 行内组装对照(K8s/entrypoint 不变,镜像构建按以下)

```bash
# ① 行外(本机已验证):构建验证镜像
cd <repo>
bash py312/download_wheels.sh        # 采购 145 wheels → py312/wheels/
docker build -f py312/Dockerfile.local-app -t cube312:local .

# ② 行内最终镜像(行内 py12 基座 + wheels + myapp)
FROM 行内py12基座
  → 源码编译版自带 /opt/python3.12.10-x86_64-bin
  → python3.12 -m venv $HOME/py312 && pip install --no-index --find-links ./wheels -r requirements.txt
  → COPY myapp /home/myapp/myapp
  → ENV PATH=$HOME/py312/bin:/home/myapp/myapp/bin:$PATH PYTHONPATH=/home/myapp
  → COPY entrypoint.sh /entrypoint.sh
# 行内注意: config.py 仍由 K8s ConfigMap 挂载(挂载覆盖镜像内空文件,与现状一致)
```
