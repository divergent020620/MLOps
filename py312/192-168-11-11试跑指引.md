## 1. 传输 + 加载(任一节点)

```bash
scp cube312-test.tar root@192.168.11.14:/tmp/      # 或任选一节点
ssh 192.168.11.14   # 后续在节点上执行
docker load -i /tmp/cube312-test.tar               # Loaded image: kubeflow-dashboard:cube312-test
```

## 2. 方式 A: docker run 直跑(最快; redis 需节点可达地址)

```bash
docker run -d --name cube312-test -p 18091:80 \
  -e MYSQL_SERVICE="mysql+pymysql://root:admin@192.168.11.15:3306/kubeflow?charset=utf8mb4" \
  -e REDIS_HOST=<redis节点IP> -e REDIS_PORT=6379 -e REDIS_PASSWORD=<redis密码> \
  kubeflow-dashboard:cube312-test

sleep 120 && curl -s http://localhost:18091/health   # 期望 OK
docker logs cube312-test 2>&1 | grep -iE "ensure tables done|Starting gunicorn|Listening"
```

## 3. 方式 B: kubectl run(推荐, 集群内服务名可用)

```bash
# 在 master1(192.168.11.11)执行; 若镜像已 load 到节点, set IfNotPresent 即用本地
kubectl run cube312-test --image=kubeflow-dashboard:cube312-test \
  --image-pull-policy=IfNotPresent --port=80 -n infra \
  --env MYSQL_SERVICE="mysql+pymysql://root:admin@192.168.11.15:3306/kubeflow?charset=utf8mb4" \
  --env REDIS_HOST=redis-master.infra --env REDIS_PORT=6379 --env REDIS_PASSWORD=admin
kubectl -n infra exec cube312-test -- curl -s localhost/health    # OK
```

> redis 密码:开发 kustomize 里 `REDIS_PASSWORD=admin`(如实际不同替换之)
