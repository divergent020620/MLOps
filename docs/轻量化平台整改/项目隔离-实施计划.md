### 任务 12：`myapp/__init__.py` — 启用静态文件 project 访问控制

**文件**：`myapp/__init__.py`
**行号**：317-319

**改动**：取消注释并增强静态文件访问控制，校验用户是否属于所访问 project 的成员

**当前代码**：
```python
    # # 判断静态文件只能访问自己的静态文件，这样代码层面的访问就都要加请求header了，比如dataset任务模板
    # if '/static/mnt' in request.path and f'/static/mnt/{g.user.username}' not in request.path:
    #     abort(401)
```

**改为**：
```python
    # 静态文件访问控制：校验用户是否属于要访问的 project
    if '/static/mnt/' in request.path:
        from myapp.models.model_team import Project_User
        # 从路径中提取 project_id，例如 /static/mnt/123/somefile
        path_parts = request.path.split('/')
        try:
            mnt_idx = path_parts.index('mnt')
            if mnt_idx + 1 < len(path_parts):
                project_id = path_parts[mnt_idx + 1]
                if project_id.isdigit():
                    # 检查当前用户是否属于该项目
                    user_in_project = db.session.query(Project_User).filter(
                        Project_User.project_id == int(project_id),
                        Project_User.user_id == g.user.id
                    ).first()
                    if not user_in_project and not g.user.is_admin():
                        abort(401)
        except (ValueError, IndexError):
            pass
```

**验证**：通过浏览器访问 `/static/mnt/{project_id}/` 路径，确认非项目成员被拒绝访问。
