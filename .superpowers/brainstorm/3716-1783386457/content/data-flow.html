你现在的模式 vs Spark 模式

关键转变：数据不动，计算动

现在：拉数据到本地

HDFS 上 100GB Parquet

→ hdfs dfs -get (下载 30分钟)

→ 本地 Python/Jupyter

→ pd.read_parquet()

→ 单机训练/推理

→ 结果写回本地

瓶颈：网络传输 + 单机内存

Spark 模式：数据不动

HDFS 上 100GB Parquet

→ spark.read.parquet("hdfs://...")

→ 500 个 Executor 各自读本地 Partition

→ 各自训练/推理

→ 结果直接写回 HDFS

优势：零数据传输 + 500 节点并行

三种读数据方式

方式代码前提
1. HDFS Parquet 路径 spark.read.parquet("hdfs://nn:8020/path/") 你已经有了 keytab + 路径
2. Hive 表（需要 Metastore） spark.sql("SELECT * FROM db.table WHERE dt='20260701'") 需要 Hive Metastore URI
3. JDBC 连 Spark Thrift jdbc:hive2://thrift-server:10000 Java 项目可以不改代码

你现在就够用的
