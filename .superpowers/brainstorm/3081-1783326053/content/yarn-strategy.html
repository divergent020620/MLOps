YARN 集群 —— 4 条技术路线对比

Spark on YARN 是 Hadoop 生态最成熟的方案。关键问题：训练还是推理？

YARN 架构下 Spark 是怎么运作的

YARN Client 模式：

你的机器(Driver) → YARN ResourceManager(申请资源) → 在 500 个 NodeManager 上启动 ApplicationMaster → AM 申请 Container → 启动 Executor → 你的 Driver 直接调度 Executor

YARN Cluster 模式：

你的机器(spark-submit) → YARN RM → 在某一个 NodeManager 上启动 Driver(AM) → Driver 再申请更多 Container 作为 Executor

四条技术路线

路线核心思路依赖大小适合
A. conda env 分发本地打好 conda 包 → 上传 HDFS → spark-submit --archives 指定 → YARN 在每个 NodeManager 解压 → Executor 用解压后的 Python 启动200MB-1GB自定义 ML
训练/推理
B. Spark MLlib直接用 spark.ml 包里的算法(决策树/随机森林/梯度提升/KMeans/LR) → 零外部依赖 → 自带特征工程(VectorAssembler/StringIndexer/OneHotEncoder)0经典 ML 训练
C. 广播模型 + UDF模型参数(.npy 或 .pkl)广播到所有 Executor → DataFrame.mapInPandas / rdd.mapPartitions → 每 Partition 内本地推理 → 零额外依赖(仅 NumPy)几MB批量推理
D. Horovod on Sparkconda env 含 Horovod → spark-submit 启动 → 每个 Executor 起一个 Horovod worker → MPI ring-allreduce 同步梯度 → 支持 PyTorch/TensorFlow 分布式训练300MB-1.5GB深度学习
分布式训练

路线 A 详解：conda env 分发（最通用）

Step 1：本地创建最小 conda 环境

conda create -p ./pyspark_env python=3.9 numpy scipy pandas scikit-learn -c conda-forge -y
# 如果需要 PyTorch：conda install -p ./pyspark_env pytorch cpuonly -c pytorch -y
tar -czf pyspark_env.tar.gz pyspark_env/
hdfs dfs -put pyspark_env.tar.gz /user/yourname/envs/

Step 2：spark-submit 提交

spark-submit \
  --master yarn \
  --deploy-mode client \
  --num-executors 50 \
  --executor-cores 4 \
  --executor-memory 8G \
  --archives hdfs:///user/yourname/envs/pyspark_env.tar.gz#pyspark_env \
  --conf spark.yarn.appMasterEnv.PYSPARK_PYTHON=./pyspark_env/bin/python \
  --conf spark.executorEnv.PYSPARK_PYTHON=./pyspark_env/bin/python \
  train.py

Step 3：train.py 里正常 import

from pyspark.sql import SparkSession
spark = SparkSession.builder.appName("ML-Training").getOrCreate()
# 现在每个 Executor 都会用解压后的 conda Python，import sklearn 没问题
df = spark.read.parquet("hdfs:///data/features/")
# ... 使用 sklearn/pytorch 做训练 ...

路线 C 详解：广播模型 + UDF 批量推理（仅 NumPy 依赖）

场景：模型已经在本机训练好了（.pkl / .npy），现在要对 100TB 数据做批量推理

# 1. Driver 加载模型 → 广播
import pickle, numpy as np
model_data = pickle.load(open("model.pkl", "rb"))
bc_model = spark.sparkContext.broadcast(model_data)

# 2. 定义 UDF，每个 Executor 从广播变量取模型做推理
def predict_batch(iterator):
    model = bc_model.value  # 本地的广播副本
    for pdf in iterator:
        X = pdf[["f1","f2","f3"]].values.astype(np.float32)
        pred = model.predict(X)
        yield pdf.assign(prediction=pred)

# 3. mapInPandas 分布式执行
result = df.mapInPandas(predict_batch, schema="...")
result.write.parquet("hdfs:///output/predictions/")
