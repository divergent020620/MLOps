# 行内 py12 基座盘点命令(镜像体检)

> 目的:摸清行内基座自带什么(python 安装方式、pip/venv 可用性、rpm 包清单与版本、关键动态库、常用命令),据此最终敲定 rpm 材料清单与 wheels 打包方式。
> 用法:把下面的"一键脚本"**整体粘贴**进基座容器的 shell 执行,把完整输出拷出来发我。

## 执行方式(二选一)

**方式 A:直接跑容器(推荐)**

```bash
docker run --rm -it <行内基座镜像名:tag> bash
# 进入容器后,粘贴下方"一键脚本"整体执行
```

**方式 B:行内 K8s 起临时 Pod(若不方便 docker run)**

```bash
kubectl run base-inspect --image=<行内基座镜像名:tag> --command -- sleep 3600 -n <任意命名空间>
kubectl exec -it base-inspect -- bash
# 粘贴下方"一键脚本"执行完毕后:
kubectl delete pod base-inspect
```

## 一键脚本(整体粘贴执行)

```bash
echo "===== 1. 系统与架构 ====="
cat /etc/kylin-release 2>/dev/null; cat /etc/os-release 2>/dev/null | head -5
uname -a; uname -m
echo "===== 2. glibc 与基础库版本 ====="
ldd --version 2>/dev/null | head -1
rpm -qa 2>/dev/null | grep -E "^(glibc|glibc-common|glibc-devel|openssl|openssl-libs|zlib|bzip2|bzip2-libs|libstdc|libgcc|pcre|expat|ca-certificates)" | sort
echo "rpm 总包数: $(rpm -qa 2>/dev/null | wc -l)"
echo "===== 3. Python 全家 ====="
for c in python python3 python3.7 python3.12; do
  cmd=$(command -v $c 2>/dev/null)
  if [ -n "$cmd" ]; then
    echo "--- $c -> $cmd"
    $c --version 2>&1
    $c -m pip --version 2>&1 || echo "pip: 无"
    $c -c "import ssl; print('ssl:', ssl.OPENSSL_VERSION)" 2>&1
    $c -m venv /tmp/venvtest >/dev/null 2>&1 && echo "venv: OK" || echo "venv: 无"
  else
    echo "--- $c: 不存在"
  fi
done
echo "--- python3 属于哪个包:"
rpm -qf $(readlink -f $(command -v python3)) 2>/dev/null || echo "非 rpm 安装(可能源码/conda/拷贝)"
echo "--- conda 痕迹:"
ls -d /root/miniconda3 /opt/conda /usr/local/miniconda3 /opt/miniconda3 2>/dev/null || echo "无 conda 目录"
conda --version 2>&1 || true
echo "===== 4. pip 配置 ====="
pip --version 2>&1; pip3 --version 2>&1
pip config list 2>&1
pip3.12 --version 2>&1
echo "===== 5. 关键 rpm 版本(漏洞对照用)====="
rpm -qa 2>/dev/null | grep -E "krb5|cyrus-sasl|libsasl|perl|libxml2|pam|libssh|libarchive|unbound|libcurl|curl|fontconfig|wqy|nginx|python3|python-pip|jq|rsync|tar|findutils|coreutils|which|sudo|vim|git|wget|iproute|net-tools|procps" | sort
echo "===== 6. yum 能力(确认是否真的无源)====="
command -v yum dnf 2>/dev/null || echo "yum/dnf: 不存在"
yum repolist 2>&1 | head -8
ls /etc/yum.repos.d/ 2>/dev/null
echo "===== 7. 关键动态库(在 /usr/lib /lib 下找)====="
for so in libgssapi_krb5.so.2 libsasl2.so.3 libssl.so.3 libssl.so.1.1 libcrypto.so.3 libz.so.1 libbz2.so.1 libpq.so.5 libcurl.so.4 libxml2.so.2 libffi.so.8 libstdc++.so.6; do
  found=$(find /usr/lib64 /lib64 /usr/lib -name "$so" 2>/dev/null | head -1)
  [ -n "$found" ] && echo "$so: $found" || echo "$so: 缺失"
done
echo "===== 8. 常用命令存在性 ====="
for c in curl wget git unzip zip tar kinit kubectl jq rsync ssh vi vim node npm nginx java mysql psql socat nc; do
  command -v $c >/dev/null 2>&1 && echo "$c: $(command -v $c)" || echo "$c: 缺失"
done
echo "===== 9. rpm 全量清单 ====="
rpm -qa 2>/dev/null | sort
echo "===== 10. 环境变量 ====="
env | grep -iE "path|python|conda|pip|locale|lang|tz|proxy" | sort
echo "===== 完成 ====="
```

## 输出回传

- 建议在容器里先 `script -a /tmp/base_inventory.log`(或直接把终端输出全选复制)存成文本,拷出行内发我;
- 如果基座里有 `script` 命令,最省事:`script -c "粘贴一键脚本" /tmp/inventory.txt` 然后 `cat /tmp/inventory.txt` 复制。

## 我拿到输出后会判断什么

| 输出项 | 判断用途 |
|---|---|
| 第 1、2 节 | 麒麟版本与架构(x86_64/aarch64 决定 rpm 与 wheels 的打包平台)、glibc 版本(补丁归谁) |
| 第 3、4 节 | py3.12 安装方式(rpm/源码/conda)、pip 与 venv 是否可用(决定行内装应用用 venv 还是 pip wheel 直装)、SSL 是否可用(HTTPS 前提) |
| 第 5 节 | krb5/cyrus-sasl/curl 等是否已自带、版本是否已含补丁(决定要补哪些 rpm、补丁版号) |
| 第 6 节 | yum 是否真的不可用、有没有残存 repo 配置 |
| 第 7 节 | 风险包 wheel(sasl/gmssl)依赖的运行库(krb5/sasl2/ssl)是否齐全 |
| 第 8、9 节 | 常用命令缺失清单(对应 §4 的 B/C 层材料)、全量包清单做漏洞版本比对 |
