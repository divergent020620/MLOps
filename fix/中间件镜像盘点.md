## 七、关键发现与待确认事项

1. **Backend TAG 不一致**: 实际运行 `cube312-test`，Kustomization 写 `kylin-20260730-v6`。需确认 `cube312-test` 基于哪个 base。

2. **中间件的麒麟基座问题**: #5-#11 的中间件镜像大多是 Go/C++ 编译的二进制 + 极简 base（Alpine/Debian-slim），不像 Python 后端那样有大量系统包。**扫描器可能也会对这些镜像报"没东西可扫"**——不是因为安全，而是 OS 层极简。这些是否需要替换为麒麟基座，需要你确认行内要求。

3. **K8s Operator 扫不了**: #12-#18 是 Go 静态编译的 CRD 控制器（`FROM scratch` / `FROM distroless`），没有 OS 层，扫描器无内容可扫。这就是为什么 k8s-manager 显示"没东西可扫"。

4. **DCGM Exporter 基于 ubuntu:20.04**: 监控栈中唯一明确基于 Ubuntu 的镜像，可能存在较多 CVE。
