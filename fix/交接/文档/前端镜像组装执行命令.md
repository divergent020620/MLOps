# 前端镜像组装执行命令(基座 + nginx最小化 + 静态产物)

> 基于 2026-09-07 两轮送评测试定稿:
> - ✅ **openssl-libs 1.1.1f-31.p29(降级)已被评估平台认可,零漏洞** —— 降级路线可行
> - ✅ **nginx 1.21.5-5.p04 已被评估平台认可,零漏洞** —— 麒麟补丁版可接受
> - ⚠ **nginx 全模块装(默认 yum install nginx)会引入 perl 5.28.3(超危 9.8)+ libtiff/libXpm(高危)—— 绝对禁止**
> - 本流程 = 最小化安装 + 静态产物;送评预期仅余基座 py3.7 的 pip/setuptools 2 条高危

---

## 步骤 1:起前端容器(独立于后端容器)

```bash
docker run -d --name fe-build01 <行内基座镜像:tag> bash -c "sleep 3600"
```

## 步骤 2:进入容器,修 yum + 拉源 + 基线

```bash
docker exec -it fe-build01 bash
```

```bash
ln -sf /usr/bin/python3.7 /usr/bin/python
yum makecache -q 2>&1 | tail -1
rpm -qa | sort > /root/rpm_before.txt
```

## 步骤 3:装最小 nginx

> ⚠ EXCL **不含** openssl/openssl-libs —— 装了 nginx 必须装它们,这是本方案的核心降级点(已验证 p29 可接受)

```bash
EXCL="glibc,glibc-common,libxml2,curl,libcurl,pam,libssh,libarchive,cyrus-sasl-lib,libstdc++,libgcc,expat,zlib,libtasn1,ncurses-libs,libuuid,util-linux,systemd-libs,libseccomp,sqlite-libs,bzip2-libs,xz-libs,libzstd,gnutls,nettle,libgcrypt,libidn2,libnghttp2,libpsl"
yum install -y nginx \
  --exclude=nginx-all-modules,nginx-mod-http-perl,nginx-mod-http-image-filter,nginx-mod-http-xslt-filter,nginx-mod-mail,perl,gd,libtiff,jbigkit-libs,libwebp,libXpm,libX11,libxcb,libXau,libxslt,man-db,gperftools-libs
```

## 步骤 4:验证(送评前必须确认,perl/libtiff/libXpm 一行都不许出现)

```bash
nginx -v
rpm -qa | grep -E "^(perl|perl-libs|libtiff|libXpm|gd|openssl|openssl-libs)" | sort
```

| 预期 | 说明 |
|---|---|
| `nginx/1.21.5`(p04) | 版本正确 |
| 出现 perl*/libtiff/libXpm/gd 中任意行 | **停止送评!** 排除没生效,把 Transaction Summary 发我 |
| openssl-libs 显示 `1:1.1.1f-31.p29.ky10` | 降级,预期内(平台已认可) |
| 只有 openssl 系输出 | 干净 ✓ |

## 步骤 5:放静态产物(<行外前端dist> 换成行外构建好的目录)

```bash
docker cp <行外前端dist目录> fe-build01:/tmp/fe-dist
docker exec -i fe-build01 bash -c 'mv /usr/share/nginx/html /usr/share/nginx/html.bak 2>/dev/null; cp -a /tmp/fe-dist /usr/share/nginx/html && ls /usr/share/nginx/html | head'
```

## 步骤 6:退出容器,commit + save(用新 tag,不覆盖任何东西)

```bash
exit
docker stop fe-build01
docker commit fe-build01 10.240.125.39/cube-studio/kubeflow-dashboard-frontend:fe-test-v2
docker save -o fe-test-v2.tar 10.240.125.39/cube-studio/kubeflow-dashboard-frontend:fe-test-v2
```

## 步骤 7:清理

```bash
docker rm fe-build01
```

## 经验记录

- 麒麟 yum 源 nginx 依赖链:全模块(all-modules)→ perl 全家 + gd/libtiff/libX11/libxslt(图像/文本库),**必须 exclude**
- 装 nginx 必然需要 openssl 包 → openssl-libs 从基座 p34 降级到源最高 p29 —— **已实测平台认可,可行**
- 若最小化 exclude 解析失败(nginx 主包硬依赖某模块),退路 = 行外自编译 nginx 1.26+ 二进制
